# Police Style Time Calculator

24 小時制時間計數機，採用深藍／金色的警務終端機風格。

> 非官方香港警務處系統；此專案只是一個個人時間計算工具。

## 功能
- 時間 + 分鐘
- 時間 - 分鐘
- 兩個時間相差幾多分鐘
- 顯示小時 + 分鐘
- 跨午夜計算
- 手機及電腦 responsive
- 純 HTML / CSS / JavaScript，適合 GitHub Pages

## GitHub Pages
上載 `index.html`、`style.css`、`app.js` 到 repository。
Settings → Pages → Deploy from a branch → `main` / `root` → Save。
